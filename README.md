# Airbnb Data Analysis (R)

A practical exploratory data analysis looking at pricing patterns, room categories, and host performance across New York City listings. Built using R.

### What This Covers
* Cleaned raw listing records, resolved missing values, and isolated heavy right-skewed pricing outliers.
* Analyzed pricing variation between boroughs and specific property types.
* Looked at whether superhost status and minimum night requirements meaningfully impact nightly rates.
* Visualized distributions and relationships using ggplot2.

### Visual Outputs
* **price_distribution.png**: Overview of listing prices across the dataset.
* **price_by_boxplot.png**: Price distributions split by room type and location.
* **superhost_price_per_guest.png**: Rate comparisons based on host status and guest capacity.

### Files
* `Airbnb_R_Code.R`: Core data cleaning, summary tables, and plot scripts.
* `Airbnb Analysis Summary.pdf`: Short report summarizing key observations and takeaways.

### Tools Used
* R
* tidyverse / dplyr
* ggplot2
